Cross-validation — engine vs. external Bayesian package

Each pool re-fit in PyMC (NUTS) — a non-centered hierarchical RE model, the Stan/brms-class comparator. DL reproduced exactly in metafor. |Δ OR| ≤ 0.02; R̂ ≤ 1.009.

The custom sampler is not driving the estimates: an independent NUTS engine reproduces every posterior within Monte-Carlo error. The only correction surfaced was six mis-reported REML values (now fixed; ✎).
